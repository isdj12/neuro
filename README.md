Классификатор свежести мяса
Приложение для определения свежести мяса с помощью нейронной сети на основе ResNet-18.

Требования
Python 3.8 или выше

Модель meat_classifier.pth (должна быть в корневой директории проекта)

Установка и запуск
1. Установка зависимостей
Bash
pip install -r requirements.txt
Примечание: PyTorch будет установлен с поддержкой CPU по умолчанию. Это подходит для инференса — модель работает быстро даже на процессоре. Если у вас есть GPU и вы хотите использовать его для обучения, установите версию PyTorch с поддержкой CUDA с официального сайта pytorch.org.

2. Проверка окружения (опционально)
Перед запуском можно удостовериться, что всё настроено правильно:

Bash
python check_setup.py
Скрипт проверит версию Python, наличие всех зависимостей и файла модели.

3. Запуск приложения
Bash
streamlit run app.py
Приложение откроется в браузере по адресу http://localhost:8501

Структура проекта
neuro/
├── app.py                # Основное приложение Streamlit
├── main.py               # Скрипт для обучения модели
├── meat_classifier.pth   # Обученная модель (необходима для работы)
├── requirements.txt      # Зависимости Python
├── dataset/              # Датасет для обучения (не требуется для инференса)
│   ├── train/
│   └── validation/
└── results/              # Директория для сохранения результатов
    └── predictions.json  # История предсказаний
Использование
Запустите приложение командой streamlit run app.py.

Загрузите изображение мяса (JPG, JPEG, PNG, BMP, WEBP).

Нажмите кнопку "Проверить свежесть мяса".

Получите результат: свежее мясо или несвежее.

Все результаты автоматически сохраняются в results/predictions.json.

Особенности
Работает на CPU (не требует GPU для инференса).

Автоматическая проверка наличия обученной модели.

Сохранение всех результатов предсказаний.

История проверок с возможностью просмотра.

Поддержка множества форматов изображений.

Что нужно для работы на другом ПК
Минимальный набор файлов для развертывания:

app.py — основное приложение.

meat_classifier.pth — обученная модель.

requirements.txt — список зависимостей.

check_setup.py — скрипт проверки (опционально).

README.md — документация (опционально).

Инструкция для нового ПК:

Скопируйте файлы: app.py, meat_classifier.pth, requirements.txt.

Установите зависимости: pip install -r requirements.txt.

Запустите приложение: streamlit run app.py.

Важные примечания
Файл модели meat_classifier.pth должен находиться в той же директории, что и app.py.

Для обучения модели используйте main.py (требуется GPU и датасет).

Решение проблем
Ошибка "Модель не обучена":

Убедитесь, что файл meat_classifier.pth находится в корневой директории проекта.

Проверьте целостность файла.

Ошибка импорта модулей:

Убедитесь, что все зависимости установлены через pip install -r requirements.txt.

Проверьте версию Python (должна быть 3.8+).
